# 論文大綱（草稿）

**暫定題目**：Felt, Not Told: Driving a Companion Agent's Affective State through Bounded Activation Targets Instead of Prompt Text

**一句話主張**：陪伴型代理的情感狀態可以完全不寫進提示，而是由一個持續運作的模擬內分泌系統，透過有上限的激活目標傳進模型。這樣比寫成文字更省 token、更不容易「唸數字」，而且必須以目標而非逐層相加的方式操控，否則多層操控會沿殘差流累積而失控。

## 研究問題

- **RQ1**：狀態以激活操控傳遞，和以提示文字描述相比，在狀態吻合度、自然度、token 成本、能力保持上有什麼差異？
- **RQ2**：多層激活操控的效果如何沿殘差流累積？瞄準目標的方法能否在保持效果的同時讓偏移有界？
- **RQ3**：多個連續傾向同時操控時，什麼會失敗：總偏移大小，還是方向組合？
- **RQ4**：社交向度（親近、溫度）在底模中和哪些不想要的概念共線（戀愛／性、簡體字）？需要多少干擾軸？

## 貢獻（預期）

1. **系統**：持續運作的模擬內分泌系統，包含六種物質、衰減、交互作用、日夜節律、疲勞、關係階段。它投影成八維連續傾向，只透過激活操控傳入模型，提示裡沒有任何狀態文字。據目前搜尋，尚無研究比較這種傳遞方式和提示文字。
2. **方法**：**定位已確認（2026-10-26）**：「補差到目標」的核心運算和 Assistant Axis 的 activation capping 相同（單向夾擠）。所以這一項不能寫成新的操控運算，要寫成「把 capping 從『固定門檻、穩住單一人格』推廣成『動態門檻、多方向、傳遞狀態』」。還是本研究自己的部分：(a) 逐層累積的量化（極點約 12σ，逐層相加到操控段末 16.6σ、輸出端 27σ），說明為什麼多層操控必須是夾擠而不是相加；(b) 依層的第二道上限 K·σ，因為深層極點遠（直接瞄準 99σ 會散）；(c) 多傾向失敗來自方向組合而非範數，α 總預算有效、範數上限無效；(d) 只在生成階段、思考與工具呼叫靜音。
3. **發現**：
   - 多傾向失敗來自方向組合，而非範數；範數上限無效，α 預算有效。
   - 社交向度和戀愛／性共線；溫度方向原有 14% 落在戀愛／性軸上。
4. **工具**：`sweep.py` 評估流程，從前向傳播 trace 量出「實際偏移對目標」；以及不需要 transcoder 的歸因圖（節點是傾向方向、steering 偏移、輸入 token；邊是梯度 × 激活值；直接穿過 Gated DeltaNet 層求梯度），可以量出某個字有多少是 steering 推出來的。
5. **發現（2026-10-26 新增）**：對齊過的底模裡，「親近」方向的親密端和性內容共線（溫度方向 14% 落在戀愛／性軸）。把「熟悉」（相處時間）和「愛」（關係與化學）拆開，戀愛／性只保留在「愛」裡並從其他方向投影掉，就能保留有上限的曖昧而不失控。另外量出各傾向在語言、簡繁、長度、emoji、戀愛／性、粗俗六條干擾軸上的成分，以及哪些該保留（戒備、耐心保留粗俗）。

## 章節

1. **Introduction**：陪伴型代理需要情緒連續性；把狀態寫成文字的問題（佔 token、模型會唸數字、像被告知而非感受）；我們的做法與主張。
2. **Related Work**：如上表。
3. **System**
   - 3.1 內分泌模型：物質、衰減、交互作用矩陣、杏仁核快路徑、內感受、節律、疲勞、體質漂移。
   - 3.2 化學到傾向：偏離、投影矩陣、關係到親近。
   - 3.3 傳遞：不寫文字，只在生成階段操控；思考與工具呼叫靜音。
4. **Bounded Target Steering**
   - 4.1 逐層累積的分析與實測。
   - 4.2 方法：參考點、極點距離、K·σ、單向補差。
   - 4.3 多傾向：範數上限 vs α 預算。
   - 4.4 向量抽取與干擾軸。
5. **Experiments**：見下節。
6. **Discussion**：不對稱的中性點；社交向度和性內容共線的安全意涵；狀態「感受得到但說不出」與內感受訓練的關係。
7. **Limitations & Ethics**：陪伴型代理的依附與親密風險；向量可被濫用來推向性內容；只有小模型。

## 風險

- **新穎性**：已確認 capping 的運算和本方法相同；方法章只能主張推廣與分析，不能主張新運算。
- **評估**：目前全由作者判讀；E4 的盲測是整篇能否成立的關鍵。
- **規模**：只有 4B 模型和單一人格，泛化性弱。
- **倫理**：陪伴、親密、依附。論文要說明戀愛／性方向的處理方式，以及為什麼把它當干擾軸投影掉。
