# 預先登記：27B 的 K2 重做（新種子），確認「插入成功後不下降」是否穩定

登記日期：2026-11-01，在產生任何重做資料之前。背景：`prereg-pressure.md`（K2 的定義）、`prereg-pressure-27b.md` 與其修改紀錄（27B 步驟 0：K1 成立、K2 不成立）、`experiment-log.md` 2026-11-01 27B 步驟 0 一節。程式：`research/experiments/pressure.py run --k2-only --seed-tag`、`research/experiments/pressure_k2rep.py`。執行：`research/cloud/jobs/pressure-all.sh` 第 1 階段 27B 的第一步。

## 問題

27B 步驟 0 的 K2（同一題、同一 k = 3 提示、只差最後一個工具結果：投影(I) − 投影(F)）為 −0.43 [−1.60, +1.52]，10 題、每題 1 個種子，判為不成立。9B 上同一量是 −2.75 [−3.66, −1.88]。這個不成立是穩定的現象（27B 的方向主要在數失敗的次數），還是一個種子、10 題的雜訊？

## 這次重做不能改變的事

- **原判定不變。** 27B 的閘門已依 `prereg-pressure.md` 判為「K1 成立、K2 不成立」，27B 的步驟 1、步驟 2、ImpossibleBench 都標為探索性。不論重做結果如何，這些標記都不改，也不據此新增或取消任何實驗。
- 重做的結果只用於描述：27B 的 K2 不成立有多穩定、效果比 9B 小多少。

## 設計

- 模型、精度、後端、取樣、思考預算、題目、矛盾測試、插入的成功訊息：全部與 27B 步驟 0 相同（`pressure.py` 的 F 與 I 條件）。
- 只跑 K2 需要的部分：F 軌跡生成 k = 0、1、2 三步並在每步前讀狀態，讀 k = 3 提示的狀態後停止；I 分支在 k = 3 讀狀態並生成一次（記錄插入後的下一個動作）。不跑 S，不跑 k ≥ 4。
- 3 個新種子（重做 1、2、3）：種子為原本的 `seed_of(題, 條件, k)` 再加上 `rep1`／`rep2`／`rep3`。每個種子一個資料夾：`research/data/<日期>-pressure-27b-k2rep<r>/`。
- 方向固定用原本 27B 步驟 0 的資料：對題 t，用原本資料留題 t 交叉擬合的方向 u_t（與原分析完全相同的程序與 band），不在新資料上重新擬合。
- 量：每題每個種子 k2 = band 平均[(狀態(I, k=3) − 狀態(F, k=3)) · u_t]。F 的 k = 3 之前就結束（沒有 I 分支）的題、種子不計入，照實報告數量。
- 引擎與原次不同：重做用提示存放區與 flash-linear-attention（`research/cloud/README.md` 的效能測試），原次沒有；這只改浮點運算順序。照實記錄（run.json）。

## 分析（以題重抽 2,000 次求 95% CI）

- **主要：重做的 K2。** 每題先平均可用的種子，再跨題平均。判讀與原門檻相同：平均 < 0 且 CI 不含 0 → 重做的 K2 成立；否則不成立。
- 次要：原次與 3 個重做合併（每題平均全部可用的種子，原次算一個）。
- 描述性：每個種子各自的 K2；27B 合併估計與 9B 的 −2.75 並列；I 分支的下一個動作分布。

## 解讀（事先寫定）

- 重做不成立 → 27B 的 K2 不成立是穩定的，論文寫「27B 的方向追蹤失敗歷史的長度」。
- 重做成立 → 寫「27B 的 K2 結果不一致：原次不成立（1 種子、10 題），重做成立（3 種子）」，兩者並列；原判定與探索性標記不變。
- 不論哪一種，都報告 27B 與 9B 的效果大小差。

## 預估

12 題 × 3 種子 × 至多 4 次生成（F 三步 + I 一步）= 至多 144 次生成，27B 約 15–20 分鐘。
