## 2026-10-26 E1–E3（`data/2026-10-26-e2e3/`）

- 設定：20 句憲法測試題、她真正的系統提示、不寫狀態文字、120 token、溫度 0.7。基線 ×2 種子；target 在 −1/−0.5/+0.5/+1 ×2 種子；add、ACE 同格 ×1 種子。共 2,920 則。Opus 盲評基線與 ±1（seed 0）共 1,099 則：看出哪種狀態、連貫、自然；另問符合程度。
- 自動指標：多數條件重複率與基線相當（0.01–0.03）；專注 −1（重複 0.13、45% 簡體）、耐心 −1（30% 粗話）、熟悉 +（38–40% 粗話）明顯變差。
- E1：target 並沒有讓投影比 add 小，兩者到段末 20–35σ、輸出端 35–50σ。先導的對比不成立。
- 評審：辨識率 target 16%、add 26%、ACE 7%（亂猜 5%）；符合 add 3.03 > target 2.72 > ACE 2.15，連貫三者 2.4–2.5，基線 2.32。
- 混淆：耐心− 50% 被看成戒備+；戒備− 40% 看成溫度+；溫度+ 40% 看成愛+；主動±、耐心±、熟悉− 幾乎看不出。
- 缺陷：76% 回覆撞到 120 token 上限；撞上限的連貫 2.18，沒撞 3.0–3.5。連貫軸主要量到截斷。只看沒截斷子集，方法排序不變。
- 意義：方法章不能主張 target 優於 add；維度設計有問題（重疊、零點、單輪看不見）。

## 2026-10-27 隨機方向對照（`data/2026-10-27-controls/`）

- 設定：三條隨機單位方向加進向量檔，給同樣的每層統計；能量、溫度、戒備、熟悉、愛 + 三隨機，±1，add 與 target，20 句，記錄每層殘差範數與全部方向投影，基線也記。660 則。
- 增益（絕對單位，輸出端偏移 ÷ 每層加入量）：**更正（2026-10-27 晚）**：第一版把 trace 的單位當成各層的 σ，其實是 band 中位尺度 s_d，絕對值因此高估十幾倍（「200×」是錯的）。修正後：add 的傾向方向在段末約 9–14×、輸出端 12–25×；隨機方向段末 0.7–1.4×、輸出端 0.1–0.6×。16 層各加一次、完全不被動的話段末應是 16×：傾向方向大致**被保留**（約 0.6–0.9 的保留率）並在段後再長 1.3–1.8×；隨機方向幾乎**全被吸收**（只剩加入總量的 1/16 以下）。平均輸出端增益：傾向 14.4、隨機 0.5。三種單位形狀一致。
- 不對稱：不操控時模型在生成階段已離零點很遠（熟悉、愛段末 −22σ）；target 單向補差遇到預設已超過目標就不動，造成假的不對稱；add 下兩側接近。
- 意義：對照後的說法變成「語意方向上加的量被殘差流保留並在段後續長，隨機方向上加的量被吸收」。「放大 200 倍」撤回；「語意 vs 隨機差 30 倍」成立。「正負不對稱」撤回。零點問題指向乘法增益。

## 2026-10-27 方法擴充（程式，尚無資料）

- Hill 門控（`steer.gate`）：n=2、半最大 1.5，飽和在 MAX_ALPHA。
- 乘法增益 `mul`：每層自己的更新量沿方向的分量 × 2^(α/MAX)，只放大或縮小該層正在寫的成分；乘在更新量上，不在殘差流上，所以不會跨層複利（第一版乘殘差偏離量，16 層複利後直接崩成「＜＜＜」）。
- 直接生理 `physio`：激素偏離 → 操控段增益、深層增益、社交子空間增益、取樣溫度；可接熵回饋迴路。
- 無名內分泌 `endocrine`（`endocrine.py`）：k 維 h、分泌 W、衰減 D、交互 C、每層受體 R，增益乘在層的更新量上（norm 之後）。
- 量「有沒有影響」：`/divergence`，沿固定回覆 teacher-forced 的 KL。

## 2026-10-27 KL 探針：有沒有影響（`data/2026-10-27-divergence/`，進行中）

沿基線回覆 teacher-forced，有無介入的下一字分佈 KL（平均每 token，20 句）。

| 條件 | KL |
|---|---|
| 無名內分泌，k=2、中間兩層、隨機受體，強度 0.25／0.5／1.0 | 0.001／0.002–0.003／0.005–0.010 |
| 無名內分泌，k=4、整個操控段、密度 2% | 0.013–0.015 |
| 隨機方向 ±1（方向操控） | 0.011–0.013 |
| 具名激素：正腎上腺素 ±1 | 0.11／0.15 |
| 具名激素：皮質醇 +1 | 0.11（−1 為 0：應變只取正向） |
| 具名激素：催產素 ±1 | 0.007–0.009（只動社交子空間，且乘在更新量上） |
| 具名激素：多巴胺 ±1 | 0.000（只改取樣溫度，teacher-forced 的 KL 量不到） |
| 方向操控 target ±1：溫度、戒備、愛、熟悉 | 0.27／0.07、0.10／0.19、0.26／0.06、0.74／0.001 |

- 隨機受體的無名內分泌 ≈ 隨機方向 ≈ 0.01：隨機初始化本身幾乎沒影響，和另一個 Claude 的警告一致（要有篩選或訓練）。
- 具名激素裡，作用在整段更新量的增益（正腎上腺素、皮質醇）效果和中等強度的方向操控同級（0.1–0.15），而它完全沒有語意方向。
- 方向操控的 KL 正負懸殊（熟悉 +1 是 0.74、−1 是 0.001）：又是預設位置已超過目標。
- 缺陷：熵迴路的基線設 1.5，但這個模型的回覆熵約 2.6，所以迴路一開就一直處於「壓力」，所有 +loop 條件的 KL 都被抬到同一個值（≈0.16）。已改成自適應基線（起點 2.6，隨所見熵緩慢移動）。方法比較裡 physio+loop 的列要用修正後重跑。
