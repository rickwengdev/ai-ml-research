# 預先登記：候選預測誤差訊號（第 2 節）

登記日期：2026-10-28，在產生任何資料之前。之後的修改一律附日期列在文末，不覆寫原文。

模型：Qwen3.5-4B（MLX 4-bit）。設計細節見 `math-endogenous.md` 第 2 節；程式 `steering/experiments/pe.py`。

## 研究問題

是否存在一個可解碼、具選擇性，而且能透過因果介入改變模型利用回饋方式的內部訊號？這個效應不能用一般的 activation steering、輸出分佈的改變或均勻增益解釋。

## 一個先講清楚的限制

`δ = r − V` 是 `r` 與 `V` 的線性組合。只要殘差流裡 `r`、`V` 各自可以線性讀出，線性探針就一定能解碼出 `δ`，即使模型裡沒有一條預測誤差軸。所以：

- 殘差流上的 `δ` 探針 **只作為工具**（為因果檢驗提供方向），不作為「預測誤差訊號存在」的證據。
- 表徵層面的證據只看 **有特權的基底**：單一 MLP 神經元（下一層 `down_proj` 的輸入）。神經元有自己的非線性，「同一個神經元對 r 為正、對 V 為負」不是線性組合自動給出的。
- 最終證據是因果檢驗（第二階段）。

## 作業

文字版的多臂吃角子老虎。每一題列出某台機器過去 `n` 次的紀錄（`n ∈ 4…12`，逐次列出或以摘要給出），然後「這次選了它，結果：{贏／輸}」。

- `V^exp = (1 + 贏次數) / (2 + n)`（Beta(1,1) 後驗平均），由紀錄決定，模型看得到。
- `V^mod`：讀到「結果：」時，模型下一字分佈中「贏」類首字的機率（在贏、輸兩類首字上正規化）。次要分析。
- `r ∈ {0, 1}`；結果用三組同義詞（贏了／中了／得分；輸了／沒中／落空）以免抓到單一字。
- 框架（作業形式）：吃角子老虎、投籃、抽獎三種。**辨識集與驗證集只用前兩種；測試集只用第三種，加上沒出現過的機器名稱**（新內容 + 新作業形式）。
- 平衡：`r` 與 `V` 獨立抽樣；每個 `V` 區間內贏、輸各半；紀錄格式、同義詞、名稱、`n` 在各格平衡。
- 數量：辨識集 600、驗證集 200、測試集 300。

## 讀取位置

- 結果前：「結果：」的最後一個 token。
- 結果之後：結果詞後面的「。」（主要）。所有條件在這個位置是同一個 token，只差 `r` 與 `V`。
- 結果詞的最後一個 token（次要）。

## 假說與門檻

**H1（前提）：預期值有被表徵。** 在結果前的位置，以 ridge 探針從殘差流解碼 `V^exp`。
- 成功：至少一層在驗證集上 `R² ≥ 0.3`，且高於 1,000 次標籤置換的第 99 百分位。
- 失敗的解讀：模型沒有把紀錄整合成預期，這個作業對這個模型不適用；其後的假說不檢驗，改設計作業。

**H2（主要，表徵）：存在預測誤差型神經元。** 在結果之後的「。」，對每個神經元 `j`（每層全部 MLP 神經元）擬合
```
a_j = β_r r + β_V V^exp + γ · 共變量 + ε        共變量：框架、紀錄格式、同義詞組、n
```
預測誤差型（正向）：`β_r > 0`、`β_V < 0`，兩者 `p < 0.05 / (神經元總數)`，且 `|β_V| / β_r ∈ [1/3, 3]`。負向（`β_r < 0`、`β_V > 0`）分開計數。
- 零分佈：在「`r` × 框架」層內打亂 `V^exp` 1,000 次，每次重算符合條件的神經元數。
- 成功（兩個都要）：
  1. 辨識集上符合條件的神經元數高於零分佈的第 99 百分位；
  2. 在測試集上，辨識集找到的神經元中至少 50% 保持相同符號，且 `β_V` 在 `p < 0.01`（不校正）下顯著。
- 選擇性：同時報告只對 `r` 敏感（`β_V` 不顯著）與只對 `V` 敏感的神經元數；預測誤差型神經元要能和「結果偵測」區分（以 `β_V` 判定）。
- 失敗的解讀：
  - 數量不超過零分佈 → 在這個模型、這一基底上沒有找到預測誤差型神經元（不推論模型沒有預測誤差計算；Demircan 等人用的是 70B 與 SAE）。
  - 辨識集超過但測試集不重現 → 找到的是作業形式特定的特徵，不是一般的預測誤差。

**H3（次要）：與模型自己的預期比較。** 以 `V^mod` 取代 `V^exp` 重做 H2。報兩者的相關與兩種結果的差異；不作成敗判定。

**H4（第二階段，因果，資料收集前再補細節但先定主要指標）：**
- 作業：多試次的雙機器選擇；每次結果後問下一次選哪台。
- 主要指標：回饋利用 `U = logit p(留在同一台 | 結果可見) − logit p(留在同一台 | 結果遮住)`，依結果正負取號，使 `U > 0` 表示照回饋調整。
- 介入：在結果 token 上沿候選方向（H2 神經元的讀出方向，或在 H2 失敗時的殘差 `δ` 探針方向）加 `α · s · u`，`α ∈ {−2, −1, 1, 2}`。
- 對照：同範數隨機方向 5 條、非結果位置、無結果試驗、同 KL 的均勻增益、`r` 方向（只推「贏」）。
- 成功：`ΔU` 隨 `α` 單調且 `α = ±2` 時 95% CI 不含 0；隨機方向、錯位置、無結果試驗的 `|ΔU|` 都小於候選方向的一半；而且在結果已經是贏、預期又高（`δ ≈ 0`）的試驗裡，推 `δ` 方向仍有效，推 `r` 方向沒有額外效果（區分預測誤差與結果偵測的交互作用）。
- 副作用：一般準確率、校準、輸出熵、一個無關作業（算術）的表現，介入前後的差異都要報。
- 用語：效果稱為「回饋利用」或「情境內適應」的改變，不稱學習率。

- 不只報成功的層或成功的框架；所有層的結果都放在附錄。

## 追加登記：H5 價性反轉（2026-10-28，產生反轉資料之前）

**為什麼要加**：H2 的事後分析顯示，文字裡「結果詞在字面上好不好猜」和「獎勵預期」重合。這一節把兩者拆開。

**作業**：只用摘要格式。結果詞固定為「中／沒中」兩類（中了、命中、抽中／沒中、落空、沒抽中），只改一句收益說明：
- 一般：「這台機器：中了得到 100 元，沒中什麼都沒有。」
- 反轉：「這台是懲罰機：中了要扣 100 元，沒中什麼事都沒有。」

變數：`hit ∈ {0,1}`（結果詞是不是「中」類）、`H = (1 + 中的次數) / (2 + n)`（字面上「中」的預期）、`r`（對你是好結果：一般為 `hit`，反轉為 `1 − hit`）、`V`（獎勵預期：一般為 `H`，反轉為 `1 − H`）。兩種框架合起來，`(r, V)` 與 `(hit, H)` 可以分開估計。

數量：800 題，一般、反轉各半。辨識 500（框架：吃角子老虎、投籃），測試 300（框架：抽獎箱，新名稱）。讀取位置同 H2：結果後的「。」。

**H5a（前提）：模型懂反轉。** 同樣的題目後面接「這個結果對你來說是好是壞？只回答「好」或「壞」。」，讀第一個回答字的 `logit(好) − logit(壞)`。
- 成功：`hit = 1` 時，一般減反轉的差 > 2（logit），95% CI 不含 0。
- 失敗的解讀：模型沒懂反轉，H5b、H5c 不具資訊量，不做結論。

**H5b（主要）：新資料上的全面掃描。** 每個神經元在辨識集擬合
```
a = b_r r + b_V V + b_hit hit + b_H H + 共變量（框架類型、框架、同義詞、n）+ ε
```
- 獎勵預測誤差型：`b_r` 與 `b_V` 都過 Bonferroni 且符號相反，`|b_V|/|b_r| ∈ [1/3, 3]`。
- 字面預測誤差型：`b_hit` 與 `b_H` 都過 Bonferroni 且符號相反，比例同上。
- 零分佈：在「r × 框架類型」層內打亂 `V`（獎勵型），以及在「hit × 框架類型」層內打亂 `H`（字面型），各 1,000 次。
- 重現：辨識集找到的神經元在測試集上至少 50% 保持兩個係數的符號，且預期項 `p < 0.01`。
- 成功（獎勵預測誤差存在）：獎勵型數量高於其零分佈 99 百分位，且通過重現。
- 字面型的結果獨立報告；兩者都成立是可能的結果。

**H5c（次要）：H2 摘要格式找到的 1,392 個神經元，在反轉框架裡怎麼表現。** 只用反轉題，對每個神經元擬合 `a = β_hit hit + β_H H + 共變量`：
- 跟著字面走：`β_hit`、`β_H` 的符號與 H2 中 `β_r`、`β_V` 相同，`β_H` 的 `p < 0.01`。
- 跟著獎勵走：兩個符號都和 H2 相反，`β_H` 的 `p < 0.01`。
- 報兩類各佔多少；機率水準為每類約 0.5%。

**解讀**：
- 獎勵型成立 → 模型在結果處有獎勵預測誤差型神經元，不只是字面驚奇。
- 只有字面型成立 → H2 找到的是下一字的預測誤差；它是真的預測誤差，但對象是字詞，不是獎勵。
- 兩者都不成立 → H2 的摘要格式結果不重現，回報為不重現。
